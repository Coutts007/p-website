Website background images
=========================

Drop images in this folder and name them:

    background-1.jpg
    background-2.jpg
    background-3.png    (any number of images; jpg, jpeg, png, webp or avif)

- background-1 is shown at the top of the page; the rest fade in one after
  another as the visitor scrolls down, in number order.
- Replace a file (keep the same name) or add/remove numbers, and the site
  updates by itself. No code changes needed. With `npm run dev` running it
  refreshes instantly; otherwise run `npm run build` again.
- Wide images (1920px or more) look sharpest.
